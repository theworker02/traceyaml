# traceyaml

Trace structured JSON yaml payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/traceyaml/

## Install / run

```bash
git clone https://github.com/theworker02/traceyaml.git
cd traceyaml
node src/cli.js
node --test
```
